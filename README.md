## 02 / Things I've built

### 智能机器人电控与方块摆放算法

`ROS` `STM32` `Beam Search`

打通 ROS 上位机与 STM32 末端执行单元的串口通信，对接气泵与步进电机控制；结合评价函数和 Beam Search 优化方块摆放策略。

**智能机器人创意竞赛 · 国家一等奖**

### 800V 高压直流 DC/DC 变换器

`DAB` `TI F280049C` `C` `PI Control`

从 DAB 拓扑选型、参数设计与控制仿真，到 DSP 控制程序开发和样机验证，参与 PI 闭环控制、硬件调试与系统性能测试。

**全国高校电气电子工程创新大赛企业赛道 · 国家二等奖**

### 单相 PFC 整流器模型预测控制

`MPC` `PFC` `MATLAB / Simulink`

围绕输入电流 THD 优化，研究电流控制信号中的三次谐波注入方案，完成算法分析、仿真对比与阶段性验证。
