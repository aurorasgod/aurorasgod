<h3><img src="./assets/p5/project-01.svg" alt="01" width="32" /> 智能机器人电控与方块摆放算法</h3>

`ROS` `STM32` `Beam Search`

打通 ROS 上位机与 STM32 末端执行单元的串口通信，对接气泵与步进电机控制；结合评价函数和 Beam Search 优化方块摆放策略。

**成果：智能机器人创意竞赛 · 国家一等奖**

<h3><img src="./assets/p5/project-02.svg" alt="02" width="32" /> 800V 高压直流 DC/DC 变换器</h3>

从 DAB 拓扑选型、参数设计与控制仿真，到 DSP 控制程序开发和样机验证，参与 PI 闭环控制、硬件调试与系统性能测试。

**成果：全国高校电气电子工程创新大赛 · 企业赛道国家二等奖**
